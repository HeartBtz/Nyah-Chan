💡 Guide des paramètres

Cette page regroupe tous les réglages de Nyah-Chan pour ce serveur. Chaque section est indépendante. N'oubliez pas de cliquer sur Sauvegarder tout en bas de la page après vos modifications.

  • Général — Préfixe des commandes textuelles et réactions automatiques.
  • Bienvenue / Au revoir — Messages envoyés quand un membre rejoint ou quitte le serveur.
  • Auto-modération — Filtre automatique des mots interdits, spam de mentions et abus de majuscules.
  • Anti-raid / Anti-spam / Anti-lien — Protections avancées contre les raids, le flood et les liens.
  • Journal de mod — Salon où les actions de modération sont enregistrées.
  • Audit Logs — Journalisation automatique des edits/suppressions de messages, changements vocaux et pseudos.
  • Starboard — Reposte les messages les plus étoilés dans un salon dédié.
  • XP / Niveaux — Système d'expérience et de niveaux avec récompenses de rôles.
  • Tickets — Système de tickets de support par boutons.
  • Ollama — Intégration d'un LLM local pour répondre aux questions des membres.
  • Escalade — Actions automatiques quand un membre accumule trop de warnings.
  • Sauvegarde — Exporter/Importer la configuration du serveur.

Général

Le préfixe est utilisé pour les commandes textuelles comme les commandes grant (ex: !vip). Les commandes slash (/warn, /ban…) fonctionnent indépendamment du préfixe.

Activer les réactions

Messages de bienvenue

Envoyé quand un membre rejoint le serveur. Pour obtenir l'ID d'un salon : Mode développeur → clic droit sur le salon → "Copier l'identifiant".

Activer les messages de bienvenue

{mention} = @mention cliquable, {user} = pseudo, {server} = nom du serveur, {count} = nombre de membres.

Messages d'au revoir

Envoyé quand un membre quitte le serveur. Mêmes variables disponibles que pour les messages de bienvenue.

Activer les messages d'au revoir

Auto-modération

Supprime automatiquement les messages contenant des mots interdits, trop de mentions, ou un excès de majuscules. Un avertissement est donné à l'auteur à chaque infraction détectée.

Activer l'auto-modération

Journal de modération

Si configuré, chaque action de modération (ban, kick, warn, timeout, purge) sera enregistrée dans le salon spécifié sous forme d'embed détaillé.

Anti-raid

Détecte un afflux massif de nouveaux membres (probable raid) et applique automatiquement une action (kick ou ban) aux arrivants.

Activer l'anti-raid

Anti-spam

Détecte le flood de messages d'un même utilisateur et le timeout automatiquement.

Activer l'anti-spam

Anti-lien

Bloque les URLs et les invitations Discord. Les domaines dans la whitelist sont autorisés (séparés par des virgules).

Activer l'anti-lien

Audit Logs avancés

Journalise automatiquement les éditions/suppressions de messages, les changements de salon vocal et les modifications de pseudo dans un salon dédié.

Activer les audit logs

Starboard

Quand un message reçoit suffisamment de réactions ⭐, il est automatiquement reposté dans un salon dédié.

Activer le starboard

Système XP / Niveaux

Les membres gagnent de l'XP en discutant. Montées de niveau annoncées automatiquement. Configurez les récompenses de rôles sur la page XP.

Activer le système XP

Tickets

Système de tickets de support. Utilisez /ticket pour envoyer un embed avec un bouton qui crée des salons privés de ticket.

Activer les tickets

Ollama Q&A

Intégration d'un modèle de langage local via Ollama. Quand un membre mentionne Nyah-Chan suivie d'une question, le bot répond via l'IA. Nécessite un serveur Ollama accessible à l'URL configurée.

Activer Ollama

Escalade automatique des warnings

Définissez des règles pour punir automatiquement les membres qui accumulent des warnings.
Nombre de warns : seuil de déclenchement. Action : timeout, kick ou ban. Paramètre : durée du timeout en minutes (ignoré pour kick/ban).
Exemple : 3 warns → timeout 60 min, 5 warns → kick, 7 warns → ban.
