Reaction Roles

Attribution automatique de rôles par réaction emoji

💡 Comment fonctionnent les reaction roles ?

Quand un membre réagit avec un emoji spécifique sur un message donné, il reçoit automatiquement un rôle Discord. Retirer la réaction retire le rôle.

  • Message ID — L'ID du message auquel les réactions sont reliées. (Mode développeur → clic droit → "Copier l'identifiant").
  • Channel ID — L'ID du salon contenant le message.
  • Emoji — L'emoji Unicode (ex: ✅) ou le nom d'un emoji custom (ex: <:nom:id>).
  • Role ID — L'ID du rôle à attribuer.
