Commandes d'attribution de rôles personnalisées

💡 Comment fonctionnent les commandes grant ?

Les commandes grant permettent de créer des commandes personnalisées (ex: !vip @user) pour attribuer un rôle à un membre. Seuls les utilisateurs autorisés peuvent les utiliser.

  • Nom de la commande — Le nom utilisé après le préfixe (ex: si le préfixe est ! et le nom vip, la commande sera !vip @user).
  • Rôle à attribuer — Nom exact du rôle Discord à donner. Créé automatiquement s'il n'existe pas.
  • IDs autorisés — Liste d'identifiants Discord (séparés par des virgules) des utilisateurs autorisés à utiliser cette commande. Pour obtenir un ID : activez le Mode développeur dans Discord (Paramètres → Avancé), puis clic droit sur un utilisateur → "Copier l'identifiant".
  • GIF — (Optionnel) URL ou chemin vers un GIF qui sera envoyé en confirmation après l'attribution du rôle.
