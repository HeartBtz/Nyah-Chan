💡 Comment fonctionnent les custom commands ?

Créez des commandes textuelles personnalisées que les membres peuvent déclencher avec le préfixe du bot (ex: !hello).

  • Nom — Le nom de la commande (sans le préfixe). Ex: hello pour déclencher !hello.
  • Type — text pour une réponse simple, embed pour un embed Discord.
  • Réponse — Le contenu de la réponse. Pour les embeds, utilisez du JSON avec les clés: title, description, color.
